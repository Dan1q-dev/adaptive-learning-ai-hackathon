# Adaptive Learning AI

Hackathon prototype of an AI learning service that:

- accepts educational materials;
- estimates a learner's current understanding;
- generates personalized exercises;
- analyzes answers and explains weak areas.

## Branches

- `main` — integrated, stable version;
- `member-1` — workspace for the first teammate;
- `member-2` — workspace for the second teammate;
- `member-3` — workspace for the third teammate.

Work in a personal branch and merge completed changes into `main` through pull requests.
